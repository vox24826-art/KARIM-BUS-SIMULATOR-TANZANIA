# KARIM BUS SIMULATOR TANZANIA

A Unity 6 prototype project for an African intercity bus simulator focused on Tanzania and the Dar es Salaam → Arusha route.

## Included prototype foundation

- Realistic bus controller tuned for a heavy coach
- Basic route progression with Tanzanian stops
- Passenger system and satisfaction logic
- Weather and lighting cycle
- Save system for local progression
- Runtime bootstrap to generate a playable prototype scene without an existing Unity scene file
- HUD for speed, RPM, gear, fuel, and route state
- Graphics quality manager with Low / Medium / High / Ultra Android presets

## Graphics target

This project is structured toward a realistic African bus-simulator aesthetic with a modern Unity 6 pipeline, realistic materials, stronger lighting, weather effects, and mobile optimization. The project includes a quality-tier system built for Android devices so the game can scale from low-end tablets to high-end flagship devices.

## Open in Unity

1. Open the folder in Unity 6.
2. Let Unity import the project.
3. Press Play in the default bootstrap scene or run the generated runtime bootstrap.

## Project goals

This project is designed as a modular prototype for future expansion into:

- More East African countries
- More routes and stations
- More bus models
- Police checkpoints
- Missions and career progression
- Android optimization for lower-end devices
- Ultra-realistic 3D art pipelines for future asset production
